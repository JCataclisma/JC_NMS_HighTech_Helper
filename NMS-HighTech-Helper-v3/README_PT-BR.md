# NMS HighTech Helper v3 - Guia em Portugues

Aplicativo offline para auxiliar com savegames de No Man's Sky.

Esta versao inclui a calculadora de criacao, leitura do inventario de pecas de Corvette, deteccao de bases do jogador e estacoes espaciais Cosmos, visualizacao do codigo de portal, deteccao de extratores/silos/tubulacoes e estimativas separadas para redes candidatas minerais e gasosas.

As redes sao inferidas por dados codificados do save. Grupos somente com silos aparecem como nao verificados. As capacidades usam 250 unidades por extrator e 1.000 por silo e nao representam a quantidade atualmente armazenada.

Consulte [README_USER.md](README_USER.md) para o guia rapido completo.
