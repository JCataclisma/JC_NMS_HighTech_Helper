# NMS HighTech Helper — Quick Start / Guia Rápido

## English (US)

NMS HighTech Helper reads your No Man’s Sky savegame locally and calculates the materials needed for a Fusion Ignitor or Stasis Device.
The app reads the player’s complete inventory and, optionally, one fixed container numbered 0 to 9. To recognize that container, its name must contain at least one of these words **in English**: `stasis`, `device`, `fusion`, or `ignitor`.
> Designed for Windows 10/11 with an up-to-date Chrome, Edge, or Firefox. Unpack the release, run `Launch NMS HighTech Helper.bat`, choose a savegame, verify the detected inventory, and calculate.

### Steps

1. Choose the language and color theme in the top-right corner.
2. Click **Load savegame**.
3. Select the desired `save.hg`, `save2.hg`, `save3.hg`, and so on. Metadata files are ignored.
4. Select the desired save candidate shown in the middle of the screen.
5. Scroll to **Detected inventory** and verify the quantities. The list includes the player inventory and one recognized fixed container, if available.
6. If no matching container is found, the app uses the player inventory only and tells you so in the source summary.
7. Scroll to **Crafting target** and choose **Fusion Ignitor** or **Stasis Device**.
8. Enter the desired quantity and click **Calculate requirements**.

The result lists all intermediate components and raw resources, including required, available, covered, and missing amounts. A negative missing value is the amount still needed.
The app runs locally in the web browser, no data grab, no data sending, no file manipulation.

## Português (BR)

O NMS HighTech Helper lê localmente o seu savegame de No Man’s Sky e calcula os materiais necessários para um Ignitor de Fusão ou Dispositivo de Estase.
O App lê todo o inventário do jogador e, opcionalmente, um container fixo numerado de 0 a 9. Para reconhecer esse container, o nome deve conter pelo menos uma destas palavras **em inglês**: `stasis`, `device`, `fusion` ou `ignitor`.
> Para Windows 10/11 com Chrome, Edge, ou Firefox. Baixe o arquivo ZIP ou o diretório completo (de mesmo nome), execute `Launch NMS HighTech Helper.bat`, escolha um savegame, verifique o inventory detectado e calcule.

### Passos

1. Escolha o idioma e o tema de cores no canto superior direito.
2. Clique em **Carregar savegame**.
3. Selecione o `save.hg`, `save2.hg`, `save3.hg` desejado. Arquivos de metadados são ignorados.
4. Selecione o save desejado entre os candidatos exibidos no centro da tela.
5. Role até **Inventário detectado** e confira as quantidades. A lista inclui o inventário do jogador e, se disponível, um container fixo reconhecido.
6. Se nenhum container correspondente for encontrado, o App usa somente o inventário do jogador e informa isso no resumo das fontes.
7. Role até **Alvo de criação** e escolha **Ignitor de Fusão** ou **Dispositivo de Estase**.
8. Digite a quantidade desejada e clique em **Calcular requisitos**.

O resultado lista todos os componentes intermediários e recursos brutos, incluindo quantidades necessárias, disponíveis, cobertas e faltantes. Um valor negativo em faltantes é a quantidade que ainda precisa ser obtida.
O App funciona localmente no navegador, e não envia nem modifica os arquivos de save.
